# BMAD artifacts

This directory holds future specifications, planning documents, story lists,
implementation records and reviews. See [BMAD.md](../BMAD.md) for the configured
locations and how to begin. No finance milestone is marked complete by setup.

Keep durable, sanitized artifacts in version control. Use synthetic examples;
exclude credentials, invitation tokens, session data and customer records.
Record the relevant commit and actual verification evidence when closing work.
